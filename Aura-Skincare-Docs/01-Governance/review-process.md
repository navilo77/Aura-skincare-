# Purpose

Defines the review workflow for documentation changes to ensure technical accuracy, business alignment, and consistency.

---

# Review Workflow

Author

↓

Peer Review

↓

Domain Review

↓

Approval

↓

Publication

---

# Review Criteria

Reviewers should verify:

- Accuracy
- Completeness
- Consistency
- Compliance
- Cross References
- Formatting

---

# Review Roles

Author

Creates the document.

Reviewer

Validates technical and business correctness.

Approver

Grants final approval.

Repository Maintainer

Publishes approved documents.

---

# Review Outcomes

- Approved
- Approved with Changes
- Changes Required
- Rejected
