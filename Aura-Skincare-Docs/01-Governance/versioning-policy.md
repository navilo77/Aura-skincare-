# Purpose

Defines the versioning standard for all documentation, APIs, architecture, and technical specifications in the Aura Documentation Repository.

---

# Objectives

- Maintain version consistency.
- Track document evolution.
- Support controlled releases.
- Simplify change management.

---

# Version Format

Semantic Versioning (SemVer):

MAJOR.MINOR.PATCH

Example:

- 1.0.0
- 1.1.0
- 1.1.2
- 2.0.0

---

# Version Rules

## Major

Increment when:

- Breaking changes
- Major architecture changes
- Repository restructuring

Example:

1.0.0 → 2.0.0

---

## Minor

Increment when:

- New features
- New APIs
- Additional documentation
- Backward-compatible improvements

Example:

1.0.0 → 1.1.0

---

## Patch

Increment when:

- Typographical corrections
- Documentation clarification
- Minor bug fixes
- Non-breaking updates

Example:

1.1.0 → 1.1.1

---

# Change Log

Every major or minor update must include:

- Version
- Date
- Summary of changes
- Author
- Approver
