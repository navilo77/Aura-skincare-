# Purpose

This directory contains the official document templates used throughout the Aura Documentation Repository.

Templates ensure consistency, readability, maintainability, and enterprise-level documentation standards.

---

# Usage

1. Select the appropriate template.
2. Copy the template.
3. Rename the new file.
4. Assign the correct Document ID.
5. Complete all required fields.
6. Submit for review.

---

# Available Templates

- Agent Contract
- API Endpoint
- Architecture
- Business Rule
- Constraint
- Data Model
- Feature
- Requirement
- Solution
- ADR

---

# Naming Convention

Examples:

REQ-001.yaml

API-001.yaml

ADR-001.md

FEATURE-001.yaml

---

# General Rules

- Do not edit template files directly.
- Always create a copy.
- Maintain document versioning.
- Follow repository naming conventions.
- Keep YAML formatting consistent.

---

# Core Principle

Every document should begin from an approved enterprise template.
