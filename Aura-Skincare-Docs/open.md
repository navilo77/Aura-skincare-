
### 💡 সহজে মনে রাখার সহজ নিয়ম:

* **যদি Backend চালু করতে চান:**
  ```powershell
  cd D:\navil\TCH\auraskincare\backend
  uvicorn app.main:app --reload --port 8000
  ```

* **যদি Frontend (ওয়েবসাইট) চালু করতে চান:**
  ```powershell
  cd D:\navil\TCH\auraskincare\frontend
  npm run dev
  ```
