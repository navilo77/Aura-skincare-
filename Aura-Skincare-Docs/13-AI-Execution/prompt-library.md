# Versioning

Every prompt must include:

- Prompt ID
- Version
- Owner
- Last Updated

---

# Rules

- Prompts must be version-controlled.
- Prompt changes require validation.
- Deprecated prompts must remain traceable.

---

# Core Principle

Prompts are managed assets, not hardcoded application logic.
