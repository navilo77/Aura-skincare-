# Purpose

Defines the execution lifecycle for all AI agents.

---

# Workflow

1. Receive Request
2. Validate Input
3. Identify Intent
4. Router selects Agent
5. Load Context
6. Execute Business Rules
7. Generate Response
8. Validate Output
9. Return Response
10. Log Interaction

---

# Agents

- Customer AI
- Admin AI
- Marketing AI
- Development AI

---

# Core Principle

Every AI response must pass validation before being returned.
