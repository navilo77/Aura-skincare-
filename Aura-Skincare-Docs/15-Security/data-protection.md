# Purpose

Defines how customer, business, and AI-related data are protected throughout their lifecycle.

---

# Data Classification

- Public
- Internal
- Confidential
- Restricted

---

# Protected Data

Customer

- Name
- Email
- Phone
- Address
- Skin Profile
- Order History

Business

- Product Catalog
- Pricing Rules
- Analytics

AI

- Prompt Library
- AI Configuration
- Evaluation Results

---

# Protection Standards

- Encrypt data at rest.
- Encrypt data in transit (TLS).
- Hash passwords using a secure algorithm.
- Minimize personal data collection.

---

# Data Retention

- Retain only when required.
- Securely delete expired data.
- Follow business retention policies.

---

# Privacy Rules

- Collect only necessary information.
- Limit access based on role.
- Never expose confidential information.

---

# Core Principle

Protect customer trust by protecting every piece of sensitive data.
